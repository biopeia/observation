Book-style table with ink rules top and bottom and hairline rows; for results, registries and comparisons.

```jsx
<DataTable number="1" caption="Battery outcomes" columns={[{key:"e",label:"Exp.",mono:true},{key:"r",label:"Result"}]} rows={rows} />
```

- `dense` for large registries. Put StatusMark in cells for status columns. No zebra, no fills.
